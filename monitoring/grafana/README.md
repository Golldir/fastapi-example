# Grafana Мониторинг

## Описание

Минимальный дашборд для мониторинга приложения с использованием Grafana и Prometheus.

## Структура

```
grafana/
├── provisioning/
│   ├── datasources/
│   │   └── prometheus.yml          # Конфигурация подключения к Prometheus
│   └── dashboards/
│       └── dashboard.yml          # Конфигурация автоматического импорта дашбордов
├── dashboards/
│   └── app-monitoring.json        # Основной дашборд мониторинга
└── grafana.ini                     # Конфигурация Grafana
```

## Запуск

1. Убедитесь, что Docker Compose запущен:
```bash
docker-compose up -d
```

2. Откройте Grafana в браузере:
- URL: http://localhost:3000
- Логин: admin
- Пароль: admin

## Дашборд включает

### Панели мониторинга:

1. **Статус подключения к базам данных** - временной график состояния PostgreSQL и Redis
2. **Текущий статус подключений** - индикаторы состояния БД (зеленый/красный)
3. **Скорость создания заказов** - rate метрика заказов в секунду
4. **Общее количество заказов** - кумулятивная метрика заказов
5. **Доступность приложения** - проверка доступности через Prometheus

### Метрики из приложения:

- `database_connection_status{db="postgres"}` - статус PostgreSQL (0/1)
- `database_connection_status{db="redis"}` - статус Redis (0/1)  
- `orders_total` - счетчик заказов
- `up{job="app"}` - доступность приложения

## Настройка

Дашборд автоматически подключается к Prometheus по адресу `http://prometheus:9090` и обновляется каждые 5 секунд.

Для изменения интервала обновления отредактируйте поле `"refresh": "5s"` в файле `dashboards/app-monitoring.json`.
