## 🧪 Тестовое задание: Микросервис обработки заказов

### 🎯 Цель
Разработать микросервис на **FastAPI**, который:
- Принимает заказы через HTTP API.
- Публикует их в **Apache Kafka**.
- Обрабатывает заказы из Kafka (асинхронно).
- Сохраняет данные в **PostgreSQL**.
- Кэширует статус заказов в **Redis**.
- Экспортирует метрики для **Prometheus**.
- Отображает метрики в **Grafana**.

---

## 📦 Требования к функциональности

### 1. HTTP API (FastAPI)
- **POST `/orders`** — создать новый заказ.
  - Тело запроса: `{ "user_id": int, "items": [{"product_id": int, "quantity": int}] }`
  - Ответ: `202 Accepted` + `order_id`
- **GET `/orders/{order_id}`** — получить статус заказа.
  - Ответ: `{ "order_id": int, "status": "pending" | "processing" | "completed" | "failed", "created_at": datetime }`

### 2. Асинхронная обработка (FastStream + Kafka)
- При создании заказа — публиковать сообщение в топик Kafka `orders`.
- Отдельный consumer (в том же или другом сервисе) читает из `orders`, обрабатывает заказ (например, имитирует обработку в течение 2–5 секунд), обновляет статус в БД и кэше.

### 3. Хранение данных
- **PostgreSQL**: таблица `orders` с полями:
  - `id` (PK)
  - `user_id`
  - `status` (default: `'pending'`)
  - `created_at`
  - `updated_at`
- **Redis**: кэшировать статус заказа по ключу `order:{order_id}` на 1 минуту.

### 4. Мониторинг
- Экспортировать метрики в **Prometheus** через `/metrics` эндпоинт:
  - Количество созданных заказов (`orders_total`)
  - Количество обработанных заказов (`orders_processed_total`)
  - Время обработки заказа (`order_processing_duration_seconds`)
  - Состояние подключения к Kafka, PostgreSQL, Redis
- Настроить **Grafana** dashboard с:
  - Графиком поступления заказов
  - Средним временем обработки
  - Статусами подключений к зависимостям

## 🛠️ Технологический стек
- **FastAPI** — веб-фреймворк
- **FastStream** — для работы с Kafka (альтернатива aiokafka + удобная интеграция)
- **PostgreSQL** — основное хранилище
- **Redis** — кэш
- **Prometheus** — сбор метрик
- **Grafana** — визуализация
- **Docker / Docker Compose** — для локального запуска всей системы

```
    └── dashboard.json       # Пример дашборда
```
